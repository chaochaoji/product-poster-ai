# Product AI — 项目汇报文案

> 电商商品属性识别与 AI 生图提示词生成系统  
> 适用场景：技术演示 / 面试展示 / 项目汇报

---

## 一、一句话概述

**上传一张商品图片 → AI 自动识别商品属性、生成三平台差异化营销文案 → 输出高质量生图提示词 → 调用即梦 Seedream 5.0 生成电商海报**，全链路 AI 驱动，覆盖 9 大品类，新增品类只需加 3 行配置。

---

## 二、项目背景与痛点

传统电商运营中，商品上架需要：
- 人工撰写商品描述和卖点
- 针对淘宝/京东/抖音三个平台分别写不同风格的文案
- 找设计师拍摄/制作商品主图、场景图、卖点图
- 周期长（3-5 天）、成本高（500-2000 元/单品）、风格不一致

本项目用 AI 把这整套流程压缩到 **30 秒内自动完成**。

## 四、技术架构亮点

### 4.1 编排层：LangGraph

| 特性 | 实现方式 |
|------|---------|
| 状态管理 | `RecognitionState` / `PromptGenState` 两个 TypedDict，全链路共享 |
| 并发执行 | Agent1 完成后，3 个文案 Agent 自动并发，无需手动管理线程 |
| 日志追踪 | `@_log_node` 装饰器，每个 Node 自动记录入口/出口/耗时/摘要 |
| 容错设计 | State 中保留 `error` + `retries` 字段，支持失败重试 |

**为什么 Task1 用 LangGraph 而 Task2 不用？**
- Task1 有明确的分支并发需求（1→3→1 拓扑），LangGraph 的 DAG 模型天然适合
- Task2 是确定性串行流程（映射→查库→合成），函数调用更简洁

### 4.2 代码+LLM 混合策略（Task2 核心设计）

| | 纯代码 | 纯 LLM | 代码+LLM（本项目） |
|---|---|---|---|
| 映射准确性 | ✅ 精确 | ❌ 可能出错 | ✅ Mapper 保证 |
| 语言流畅度 | ❌ 机械 | ✅ 自然 | ✅ LLM 合成 |
| 平台风格融合 | ❌ 生硬拼接 | ✅ 自然融入 | ✅ 三层注入 |
| 可维护性 | ✅ | ❌ 黑盒 | ✅ 配置驱动 |

**三层知识注入**：少样本（System Prompt 内嵌保底）→ 知识字典（prompt_kb.py 核心可积累）→ 联网搜索（兜底未知品类）

### 4.3 平台差异化：五层联动

不是简单的"换关键词"，而是通过 5 层机制联动保证三个平台的文案和视觉真正不同：

```
用户选平台 → platform 参数
    │
    ├─ config.py      色调/氛围/布光三套预设（暖橙 vs 冷蓝 vs 暖柔）
    ├─ mapper.py      注入 4 个模块（布光/背景/风格/营销）
    ├─ prompt_kb.py   品类×平台商业摄影参考（如淘宝美妆618 vs 京东自营）
    ├─ synthesis.yaml Agent3 融合指令："自然融合，禁止拼接"
    └─ Agent3(LLM)    输出自然语言差异化提示词
```

| 维度 | 淘宝 | 京东 | 抖音 |
|------|------|------|------|
| 人设 | 促销导购 | 专业测评师 | 种草博主 |
| 色调 | 暖橙红高饱和 | 冷蓝灰高对比 | 暖柔粉低饱和 |
| 必用词 | 限时/抢购/爆款 | SGS/参数/正品 | 谁懂/姐妹们/闭眼入 |
| 禁用词 | SGS/参数/正品 | 限时/抢购/手慢无 | SGS/性价比/统计 |

### 4.4 卖点质量保证（防空洞）

- System Prompt 要求 5~8 个卖点，覆盖至少 5 个维度类别（材质/功能/设计/工艺/场景/规格）
- 每个类别最多 2 个，按营销说服力排 priority
- Few-shot 示例：正确 vs 错误对比
- **20+ 禁用词黑名单**："质量好""性价比高""非常好"等空洞词直接拦截
- 输出后 Pydantic v2 强校验，不合格自动重试

### 4.5 可扩展性：新增品类只需三行

```python
# 1. config.py — 加品类维度映射
CATEGORY_DIMENSION_MAP["宠物用品"] = ["材质","安全性","适用体重","功能","设计"]

# 2. config.py — 加场景风格
CATEGORY_SCENE_MAP["宠物用品"] = {"style":"温暖居家","palette":"米白木色","props":"宠物玩具"}

# 3. prompt_kb.py — 加摄影参考（可选）
("宠物用品", "main"): {"ref":"Purina/Royal Canin 官图","lighting":"柔光窗光+反光板"}
```

框架代码 **零修改**。

## 六、技术栈

| 组件 | 选型 | 说明 |
|------|------|------|
| **编排框架** | LangGraph | 多 Agent 状态流转、并发执行 |
| **识别模型** | 豆包 Seed 2.0 Lite（火山方舟） | 多模态图片理解 |
| **文案/合成模型** | 豆包 Seed 2.0 Lite（纯文本） | 3 Agent 并发 + 提示词合成 |
| **生图模型** | 即梦 Seedream 5.0 | 支持参考图模式保持产品还原 |
| **Web 框架** | FastAPI + Uvicorn | 轻量 API，Swagger 自动生成 |
| **数据校验** | Pydantic v2 | 强类型，输出格式保证 |
| **Prompt 管理** | YAML 集中管理 | 非开发人员可直接修改 |
| **图片处理** | Pillow | 文字叠加、图片合成 |
